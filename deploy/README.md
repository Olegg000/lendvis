# Переезд сайта на новый сервер за 5 минут

Весь контент собирается из исходников, поэтому «резервная копия» — это эти скрипты.
Ничего с диска старого сервера сохранять не нужно.

## Порядок при смене локации / провайдера

1. Взять новый VPS (Ubuntu 22/24), узнать его IP и root-доступ.
2. Скопировать эту папку и поднять окружение:
   ```
   scp -r deploy root@NEW_IP:/root/
   ssh root@NEW_IP 'bash /root/deploy/provision.sh'
   ```
   (nginx, своп 2 ГБ, ufw, fail2ban — всё ставится само)
3. В панели домена сменить A-запись `lendvis.ru` и `www` на NEW_IP.
   Дождаться прогона: `dig +short A lendvis.ru` должен показать новый IP.
4. Выпустить сертификат на сервере:
   ```
   ssh root@NEW_IP 'bash /root/deploy/cert.sh'
   ```
5. Залить сайт с локальной машины (из корня репозитория):
   ```
   bash deploy/deploy.sh NEW_IP
   ```
6. Старый сервер можно гасить.

## Обновление сайта потом
Одна команда из корня репо: `bash deploy/deploy.sh <IP>`

## Зеркало
Даже если сервер недоступен, сайт всегда есть на GitHub Pages:
https://lendvis.github.io/ — деплоится сам при пуше в main.
